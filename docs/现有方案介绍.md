# 当前方案介绍

更新时间：2026-07-13

本文是当前正式汇报口径。任务是**频率感知的少样本、仅正常样本 RF 频谱异常检测**；不记录已经废弃的 PromptAD 文本融合、重构支线或历史调参过程。

## 1. 应用场景与问题定义

目标场景是 RF 监测系统的**部署冷启动**：新接收机、新地点或新频段刚上线时，系统只能采到极少量已经确认正常的频谱图。异常干扰本来就稀少、难以预先收集，且实际出现的异常类型未知。

```text
给定：每个目标频段 1 张 target normal support 频谱图
未知：后续频谱是否异常，以及异常具体属于什么类型
限制：不使用 target abnormal 图像或异常标注训练、建库或选模型
目标：仅凭少量 normal support 检测未知异常
```

这个设定对应实际的短采集窗口、设备/场景变化和频段变化：旧环境的 normal 数据无法直接代替当前目标环境的数据，因此不能假设有大量 target normal 样本。

主实验使用 `per_frequency`：每个目标频段保留 1 张 normal support，以覆盖不同频段的正常外观。这仍是 few-shot，因为每个频段只需极少量正常图；同时它符合 RF 部署现实，避免随机抽取少量图却遗漏某些频段。频段采样是 support 构建策略，不属于方法推理结构的一部分。

## 2. 方法概览

方法名称：**Confidence-Gated Dual Visual Normality Fusion**。

核心思路：只用少量 target normal 图像建立两种互补的视觉正常记忆库；CNN 只在其局部证据足够可靠时补充 ViT 的结构异常分数。

### 频谱图的独特性

RF STFT 频谱图的两个方向分别对应时间和频率，亮度反映局部信号能量，不能像普通图片一样随意旋转或翻转。它的正常背景受频段、设备和场景影响，异常又常表现为少量局部能量变化。因此，本方法用目标域 normal memory 建立参照，用 ViT 看整体时频结构、CNN 看局部细节，并只沿时间轴做配对 TTA 处理轻微错位。

```text
few-shot target normal support
          |
          +--> Paired STFT TTA --> ViT normal patch memory
          |
          +--------------------> CNN local normal memory

test spectrogram
          +--> ViT patch matching --> ViT score
          +--> CNN local matching --> CNN score --> confidence gate
                                                |
                                  ViT score + gated CNN evidence
                                                |
                                        final image score
```

当前最终分数不使用 text score。target normal support 只用于建立 ViT/CNN normal memory，不使用 target abnormal 图像或其标注。

正式配置为：ViT 使用 `Farthest-First Coreset`（保留比例 `0.5`）和 `top-k NN`（`k=5`），并启用四视图 paired STFT TTA；CNN 使用完整 local memory 和单最近邻，不启用 CNN TTA；最终使用无标签 confidence gate 融合两条视觉证据。

### 主要创新点

1. **面向 RF 冷启动的 normal-only few-shot 检测。** 只用目标环境极少量正常频谱图建立 memory，不依赖目标异常样本或异常类别，适合异常类型未知的部署场景。
2. **Paired STFT TTA。** 针对频谱图的时间错位和局部噪声构造原图、模糊、时间轴上移和下移四个视图；support 与测试图使用对应视图匹配，避免把普通图像增强直接套到频谱上。
3. **按特征性质设计不同的正常记忆库。** ViT 使用 `Farthest-First Coreset + top-k NN`，在减少重复 patch 的同时保持全局结构覆盖和距离稳定性；CNN 保留完整局部 memory 和单最近邻，保护少量但有意义的局部模式。
4. **无固定权重的置信度门控融合。** CNN 不是直接与 ViT 做均值或固定比例相加，只有当 CNN 在当前无标签测试单元中排名较高且证据强于 ViT 时才参与增强，从而让 ViT 负责主判断、CNN 补充局部异常。

## 3. 两条视觉分支

### ViT Normal Patch Memory

ViT 分支负责识别全局时频结构和 patch 级形态偏离。

```text
normal support images
  -> ViT patch features
  -> farthest coreset: 去掉重复 normal patches，保留多样代表
  -> normal patch memory

test image patches
  -> 与 memory 做 top-k nearest-neighbour matching
  -> 平均 top-k 距离形成 patch anomaly map
  -> map 最大值作为 ViT image score
```

- **farthest coreset**：从少量 normal patch 中挑选相互差异更大的代表，减少重复背景对 memory 的占用。
- **top-k NN**：测试 patch 不只看一个最近 normal patch，而是看多个近邻的平均距离，降低偶然匹配带来的波动。

### CNN Local Memory

CNN 分支负责补充局部纹理、亮线和局部能量块等细粒度变化。

```text
normal support images
  -> CNN local features -> CNN local memory

test image local features
  -> nearest-neighbour distance to CNN memory
  -> CNN image score
```

它借鉴 PatchCore 的 normal local memory 思路，但在本方法中只作为第二种视觉证据，而不是单独的最终系统。

### 为什么两条分支采用不同的匹配规则

ViT 和 CNN 不是同一种特征，因此不强行使用同一套 memory 处理方式：

- **ViT 使用 farthest coreset + top-k NN。** ViT patch 的感受野更大，同一张频谱图中会产生大量相似的结构 patch。farthest-first coreset 去掉重复背景，同时保留不同时间-频率结构的代表；top-k NN 再对多个相近正常结构取平均，避免单个偶然近邻决定结构异常分数。ViT 负责主结构证据，因此需要兼顾 memory 的覆盖性和分数稳定性。
- **CNN 保留完整 local memory + 单最近邻。** CNN 特征的感受野更小，局部亮线、能量块和细弱纹理可能只由少数 patch 表示。用 coreset 压缩可能误删罕见但正常的局部模式，造成误报；用 top-k 平均则会把小范围局部异常的距离摊平。CNN 在系统中只是辅助证据，所以优先保留局部敏感性，再交给 confidence gate 判断是否增强 ViT。

这不是为了让两个分支形式上对称，而是按特征的作用分工：ViT 优先保证全局结构覆盖和稳定性，CNN 优先保证局部异常敏感性。消融也支持这一选择：public RF 同时去掉 ViT coreset/top-k 后 macro Image-AUROC 从 `88.92` 降至 `88.36`，DSSS 从 `83.51` 降至 `82.40`；CNN coreset 的严格对照从 `88.92` 降至 `88.79`，CNN top-k 没有稳定收益。

## 4. STFT Paired TTA 与融合

ViT 分支使用 4 个同源视图：`original`、`blur`、`time shift up`、`time shift down`。`blur` 是 `3x3` Gaussian blur；两个平移视图沿时间轴分别移动 `-4 px` 和 `+4 px`。

每个视图各自建立 normal memory，测试时也只与同类型视图的 memory 匹配，最后将四张 anomaly map 取最大值。这样可减轻频谱图中轻微时间错位和细碎噪声的影响。

CNN 不做固定权重平均，而是通过无标签置信度门控 OR 融合。CNN 只有在当前测试单元中排名较高、且其局部异常证据强于 ViT 分数时，才增强最终结果。

```text
V, C = ViT score, CNN score
v = minmax(V), c = minmax(C)                   # within one test cell
r = percentile_rank(C)                         # within the same test cell
g_rank = max((r - 0.5) / 0.5, 0)
g_adv  = max(c - v, 0)
g = g_rank * g_adv
final = 1 - (1 - v) * (1 - g * c)
```

正式配置为：`rank_q=0.5`、`gamma=1.0`、`margin=0`。因此，CNN 未超过 ViT 分数或不在当前单元的高分段时，`g=0`，最终分数退化为 ViT 分数。该门控不读取测试标签，但会使用同一测试单元的无标签分数集合计算相对排名；它属于批次级无标签推理，而非单张图独立校准。直接 OR、均值融合和调和融合仅作为消融对照。

## 5. 实验协议

| 数据集 | normal support 采样 | 测试内容 | 主指标 |
|---|---|---|---|
| self RF | `per_frequency` | 独立 normal + 各异常类型、各 JSR | macro Image-AUROC |
| public RF | `per_frequency` | 独立 normal + burst/chirp/dsss/pulse 各 JSR | macro Image-AUROC |

`per_frequency` 表示正常 support 按频段覆盖。两套主协议都只使用 target normal support 建库，不使用 target abnormal 或其标注参与建库、训练或选模型。Spectrum 缺少频段元数据，不能实施该协议，因此不作为当前主实验。

## 6. 指标说明

- **ROC 曲线**：改变异常分数阈值，记录真正例率（TPR）和假正例率（FPR），展示不同阈值下的检测取舍。
- **Image-AUROC**：图像级 ROC 曲线下面积，衡量异常图像是否整体排在正常图像前面；`0.5` 接近随机，`1.0` 表示理想区分。
- **Image-AUPRC**：图像级精确率-召回率曲线下面积。异常样本较少时，它更能反映误报和漏报的影响，越高越好。
- **FPR@95%TPR**：当异常召回率达到 `95%` 时，被误报为异常的正常图像比例，越低越好。

这里的指标都是图像级指标，**self RF 和 public RF 必须分别计算，不能合并两套数据集的样本后计算 ROC**。每个数据集先独立计算 ROC、Image-AUROC、Image-AUPRC 和 FPR@95%TPR，再在该数据集内部按异常类型/JSR 测试单元做宏平均。测试标签只用于最终计算指标，不参与 support 建库、训练或分数校准。

当前正式方案的指标按数据集分别汇总。ROC 是曲线文件，不是一个单独的标量；其余三项是对应数据集内部测试单元的宏平均。

## 9. 当前结论

当前正式方案是一个 normal-only 的双视觉 normal memory 系统：ViT normal memory 提供结构异常证据，CNN normal memory 提供局部异常证据，无标签的 confidence-gated OR fusion 决定 CNN 证据是否参与增强最终分数。

它在两个 RF 少样本数据集上超过 PatchCore-style baseline，并相对 PromptAD text + ViT baseline 在 self RF 和 public RF 分别提升 `+1.96` 和 `+1.30`。后续报告和架构图均以本方案为准；Spectrum 不作为当前主结果。
