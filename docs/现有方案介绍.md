# 现有方案介绍

更新时间：2026-07-02

本文只说明当前最新方案，作为后续对外介绍、画架构图和实验对比的统一依据。

## 1. 当前方案一句话

当前方案是在 PromptAD 的 RF 频谱异常检测框架上，加入两个只由 target normal 样本构建的正常性参照分支：

```text
PromptAD RF semantic score
+ CLIP target-normal gallery distance
+ ResNet18 local normal-gallery distance
=> final image anomaly score
```

也就是说，PromptAD 负责给出“语义异常倾向”，CLIP gallery 和 ResNet gallery 负责回答“这张频谱图像不像当前目标域的正常样本”。

## 2. 当前实验协议

当前主线使用统一的 target pooled normal-only 协议。

训练集：

```text
burst_signal + chirp_signal + dsss_signal + pulse_signal
4 anomaly types x 4 scenes x 3 JSR = 48 cells
每个 cell 只取 75% normal
全部 normal 合并训练一个 universal checkpoint
```

测试集：

```text
每个 cell 单独测试
test = 剩余 25% normal + 当前 cell abnormal
```

固定数据范围：

```text
burst_signal: m10db, m20db, m30db
chirp_signal: m10db, m20db, m30db
dsss_signal : m10db, m20db, m30db
pulse_signal: m20db, m30db, m40db
```

固定训练设置：

```text
prompt_mode = rf
input_mode = rgb
normal_train_ratio = 0.75
seed = 111
epochs = 20
batch_size = 400
checkpoint = one overall-best checkpoint
```

重要约束：

- 不使用 target abnormal 参与训练。
- 不使用 target abnormal mask 参与 CLS 训练。
- 不做单库训练。
- 不选择 per-class best checkpoint。
- 所有类别共用一个 universal checkpoint。

## 3. 系统结构

当前系统由三条证据分支组成。

```text
RF spectrogram image
        |
        v
PromptAD / CLIP image encoder
        |
        +--> Text prompt branch
        |      normal / abnormal RF prompts
        |      -> PromptAD image score
        |
        +--> CLIP normal gallery branch
        |      target train normal features
        |      -> CLIP target-normal distance score
        |
        +--> ResNet18 local gallery branch
               frozen ResNet18 local features
               target train normal local feature gallery
               -> local morphology distance score
```

三条分支最后融合成图像级异常分数。

## 4. PromptAD RF 分支

PromptAD 原本用于通用工业异常检测。我们保留它的 prompt learning 机制，但把文本语义改成 RF 频谱任务。

当前类别名统一为：

```text
radio frequency spectrogram
```

异常 prompt 描述 RF 频谱中的异常能量、干扰和时频结构变化，而不是普通工业图像里的破损、划痕、缺陷。

这个分支的作用是提供语义方向：

```text
这张频谱图更像 normal RF spectrogram，
还是更像 abnormal RF spectrogram。
```

## 5. CLIP Normal Gallery 分支

CLIP gallery 使用 PromptAD/CLIP 自身的图像特征。它只从 target train normal 样本构建正常特征库。

逻辑很简单：

```text
target normal images
  -> CLIP image features
  -> normal gallery

test image
  -> CLIP image feature
  -> 距离 normal gallery 越远，越异常
```

这个分支的价值是和 PromptAD 主干特征空间一致，比较稳定。

## 6. ResNet18 Local Gallery 分支

ResNet18 gallery 使用冻结的 ImageNet 预训练 ResNet18，不训练 ResNet 参数。它提取局部视觉形态特征，用 target train normal 样本建立局部特征库。

逻辑是：

```text
target normal images
  -> frozen ResNet18 local features
  -> local normal gallery

test image
  -> frozen ResNet18 local features
  -> 每个 patch 找最近 normal patch
  -> 距离越高，局部越不像正常频谱结构
```

它补的是 PromptAD/CLIP 不够细的局部形态信息，例如亮线、斜线、局部能量块、纹理和弱结构偏离。

## 7. CLS 分数融合

图像级异常分数采用加法融合：

```text
S_final = S_promptad + lambda_clip * D_clip + lambda_resnet * D_resnet
```

含义：

- `S_promptad`：PromptAD 原始 image anomaly score。
- `D_clip`：测试图像到 CLIP target normal gallery 的距离分数。
- `D_resnet`：测试图像局部 patch 到 ResNet normal gallery 的距离聚合分数。

当前最优设置：

```text
CLIP top-k normal gallery distance
ResNet18 layer3 local gallery
ResNet patch top 10% distance average
lambda_clip = 1.0
lambda_resnet = 0.5
```

当前最佳 CLS 方法名：

```text
resnet18_layer3_dual_raw_clip1_resnet0.5
```

## 8. SEG 分数融合

SEG 不是当前应用最核心的任务，但可以作为可解释性和定位能力的补充证据。

SEG 使用乘性门控，而不是简单加法：

```text
M_final = M_text * (1 + beta_clip * M_clip) * (1 + beta_resnet * M_resnet)
```

含义：

- `M_text`：PromptAD textual anomaly map。
- `M_clip`：CLIP normal gallery patch distance map。
- `M_resnet`：ResNet local normal gallery distance map。

这样设计的原因是：text map 仍然是主控信号，视觉距离分支只在 text 已经怀疑的位置增强异常响应，减少视觉距离单独制造假阳性的风险。

当前最佳 SEG 设置：

```text
ResNet18 layer3
beta_clip = 0.1
beta_resnet = 0.1
```

当前最佳 SEG 方法名：

```text
dual_gate_resnet18_layer3_clip0.1_resnet0.1
```

## 10. 当前方案的核心贡献

当前方案的核心贡献是：

1. **RF 语义适配**：把 PromptAD 的文本提示词从通用工业缺陷改为 RF 频谱异常语义。
2. **Target normal calibration**：只用 target normal 样本建立正常性参照，不使用异常样本训练。
3. **双视觉正常性校准**：同时使用 CLIP 全局/语义视觉特征和 ResNet18 局部形态特征。
4. **统一 checkpoint**：四类异常合并训练一个 universal checkpoint，而不是每类单独选 best。
5. **轻量可解释**：新增分支都是冻结特征提取 + normal gallery 距离，不训练大模型。

## 11. 当前结论

当前最值得保留的主线是：

```text
PromptAD RF prompt
+ RGB input
+ CLIP target normal gallery
+ ResNet18 local normal gallery
```

对于 CLS，dual gallery fusion 已经明显超过 pooled `rf+rgb` baseline，是当前最有文章价值的方向。

对于 SEG，虽然不是核心应用目标，但 dual gallery gate 也有稳定正收益，可以作为可解释性和定位能力的补充实验。

后续架构图和论文方法部分应围绕这个名字展开：

```text
Dual Visual Normality Calibration for RF PromptAD
```
