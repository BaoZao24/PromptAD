# 现有方案介绍

## 场景与问题

本文面向无线通信系统中的**频谱异常检测**。系统通常把连续采集到的无线信号转换为
时间—频率频谱图：横轴表示时间，纵轴表示频率，颜色或亮度表示对应位置的能量。检测器需要
判断一张新的频谱图是否仍然符合当前场景的正常通信状态，或者出现了额外的突发、扫频、脉冲、
扩频、欺骗式信号或其他干扰。

真实部署时，系统经常会进入新站点、新频段或新的 OFDMA（Orthogonal Frequency Division
Multiple Access，正交频分多址）配置。此时通常只能快速采集少量确认正常的频谱图，却没有
足够的目标场景异常样本和异常标签；同时，合法业务占用、噪声底、信号功率和设备状态也会
随场景变化。若直接沿用旧场景的阈值或重新训练一个监督分类器，就容易把正常变化误报为异常，
也难以及时覆盖新出现的干扰类型。

因此，我们关注的是一个面向实际部署的**少样本正常冷启动问题**：只给检测器少量目标场景
正常频谱图，能否快速认识“正常状态长什么样”，并对后续频谱观测逐张独立判断？理想方案应
同时观察整体时频布局和局部纹理变化，不能依赖异常训练样本，也不能依赖同一测试批次的统计
信息。

本文提出一种**目标域免训练的记忆式学习范式**：传统方案是“收集数据—训练模型—部署”，
本文则是“冻结模型—建立正常记忆—直接查询”。系统只需读取少量正常频谱图，就能建立一个
可直接查询的 Frequency-Aware Dual-Scale Normal Memory Bank（频谱感知双尺度正常记忆库）。
冻结的 ViT 记忆整体时频结构，冻结的 CNN 记忆局部纹理；新样本到来后逐张与正常记忆匹配，
再由记忆库校准的置信度规则决定是否接纳局部证据。新站点、新频段或新通信配置无需等待异常
样本，也无需重新训练模型，即可快速上线检测。

这里的“免训练”特指**目标域免训练**：通用预训练 backbone 保持冻结，目标场景不进行反向
传播、参数更新、分类器微调或异常样本训练。方法仍然能够“认识”新场景，但学习的载体从模型
参数变成了正常 memory bank——新增正常样本只更新场景记忆，不改动网络权重。每张测试图都
可以独立处理，不依赖同一测试批次的统计信息。

本文将用于建立正常参考的少量正常样本简称为 `support`，也就是“正常参考样本”。

## 1. 核心创新与卖点

- **创新 1——从参数学习转向记忆学习**：提出目标域免训练的少样本适配范式。部署阶段不
  训练分类器、不微调 backbone、不进行梯度更新，也不需要异常样本；系统通过建立和更新
  正常 memory bank 学习新场景，几张正常图像即可完成冷启动。
- **创新 2——频谱感知双尺度正常记忆库**：将少量正常样本组织成可查询的双分支知识载体。
  ViT `layer1+layer2` 记忆整体时频布局，CNN ResNet18 `layer3` 记忆局部亮线、脉冲和
  纹理；异构近邻匹配保留两种互补证据。RF 中还按频段组织 support，避免少量样本的频段
  覆盖失衡。
- **创新 3——记忆库校准的置信度融合**：正常 memory 不仅用于近邻检测，还用于估计两条
  分支的正常波动范围。CNN 只有相对正常记忆足够异常、且证据强于 ViT 时才参与非负修正，
  从而避免简单拼接或无条件相加带来的局部误报。
- **创新 4——频谱采集变化鲁棒的 paired TTA**：针对频谱图的坐标语义设计成对视图，重点
  覆盖两类部署变化：采集窗口的轻微对齐差异，以及接收机/环境造成的噪声底波动。support
  和 query 使用一致的频谱视图，再进行 normal memory 匹配，使正常采集变化不被误判为
  异常。当前实现是探索候选，尚未替换正式 TTA。

- **整体架构价值**：把“少量正常样本、冻结 backbone、正常记忆库、逐样本近邻查询”组合成
  一个不依赖异常训练数据的检测闭环。它不是完全不适应新场景，而是把昂贵的参数训练替换为
  轻量的记忆更新，实现“正常样本到位即可检测”的快速部署。
- **主线配置**：ViT `layer1+layer2`，CNN ResNet18 `layer3`。
- **结果**：本文方法在四个数据集的同协议比较中均取得最高 AUROC。
- **边界**：OFDMA 的 ViT-only 略高于融合；FedJam 上 PatchCore 的高召回误报率更低。

## 2. 要解决的问题

新站点、新频段或新的正交频分多址（Orthogonal Frequency Division Multiple Access，
OFDMA）配置中，通常容易获得少量正常观测，却难以及时收集覆盖充分的异常样本。与此同时，
合法背景、噪声底和占用方式会随场景变化，弱干扰还可能只表现为局部纹理异常。

因此，检测器需要同时满足：

- 只用目标场景的少量正常样本建立参考；
- 同时观察整体时频布局和局部异常纹理；
- 测试样本逐张独立处理；
- 避免局部分支过度敏感导致误报。

## 3. 方案概览

```text
少量正常参考样本
   ├─ ViT layer1+layer2 正常参考特征 ──> 全局结构分数 V（主判据）
   └─ CNN layer3 正常参考特征 ─────────> 局部纹理分数 C（补充证据）

待测频谱图 ──> 双分支异常分数 ──> 只用正常参考的置信度融合 ──> 最终分数
```

![当前纯视觉方案架构图](../纯视觉架构图.png)

| 模块              | 作用                                                        |
| ----------------- | ----------------------------------------------------------- |
| ViT normal memory | 建模合法信号的整体时频布局与跨区域关系                      |
| CNN local memory  | 感知亮线、脉冲、边缘和局部纹理突变                          |
| Paired TTA        | 在一致的频谱语义视图中比较 query 与 normal memory；新增候选使用时间双向平移和背景噪声底抖动 |
| Confidence Fusion | 仅在 CNN 相对正常 support 足够异常且强于 ViT 时加入非负修正 |

简单来说，先从少量正常图像中提取“正常长什么样”的参考特征，再判断待测图像与这些参考的
差异。表中的 `normal memory` 指正常参考特征，`query` 指待测图像，`support-only` 指融合
规则只由正常参考样本确定。

融合分数为：

$$
s=V+2.5\,\operatorname{IQR}(R_V)[p_C-p_V]_+
\mathbf{1}\{\hat r_C\geq0.8\}.
$$

其中，$V$ 是 ViT 的全局结构分数，$p_V$ 和 $p_C$ 分别是 ViT、CNN 根据正常参考样本校准
后的有界异常证据（不是监督校准的异常概率），$\hat r_C$ 是 CNN 分数在正常参考中的相对
排名，$[u]_+=\max(u,0)$。只有
当 CNN 的异常程度达到正常参考分布的高分位（$\hat r_C\geq0.8$），且 CNN 证据强于 ViT
时，CNN 才会对 ViT 分数进行非负修正；否则直接保留 ViT 分数。

这里的 **IQR（interquartile range，四分位距）** 是正常参考分数中间 50% 的跨度：

$$
\operatorname{IQR}(R)=Q_{75}(R)-Q_{25}(R),
$$

其中 $Q_{25}$ 是第 25 百分位数，$Q_{75}$ 是第 75 百分位数。比如正常 support 分数的
$Q_{25}=10$、$Q_{75}=14$，则 IQR 为 $4$，表示正常分数中间一半大致分布在宽度为 4 的
范围内。IQR 越小，说明正常分数更集中；同样大小的偏离就更值得关注。IQR 越大，说明正常
波动本身更宽，公式会相应降低对单个分数偏离的敏感度。这里的 IQR 分别从 ViT/CNN 的正常
memory 参考分布计算，不是模型训练出来的参数，也不是异常概率。

我们使用 median（中位数）描述正常分数中心、IQR 描述正常波动尺度，而不是 mean/std；少量
support 中出现极端视图时，median/IQR 通常比均值/标准差更不容易被拉偏。实现中还加入很小
的 $\epsilon$，当正常参考分数几乎相同时避免除零。

该公式由三条设计原则构成：用正常 memory 的 median/IQR 消除两分支量纲差异；用 CNN
正常排名的上尾门槛抑制局部纹理误报；用 $[p_C-p_V]_+$ 只加入 CNN 相对 ViT 的增量证据。
系数 `0.8/2.5/2.5` 是开发阶段选择后冻结的保守参数，不是理论上唯一的最优常数。完整推导、
数值例子与参数选择依据见 [`置信度计算方法.md`](置信度计算方法.md)。

### 融合公式的来源与设计依据

这个公式不是直接引用某篇论文的现成公式，而是本文针对“少量正常样本、目标域不训练、逐张
独立检测”设计的 **support-only 非对称分数融合**。它借鉴了三类已有思想：PatchCore 的
正常 memory bank 与近邻检索机制（[PDF](https://openaccess.thecvf.com/content/CVPR2022/papers/Roth_Towards_Total_Recall_in_Industrial_Anomaly_Detection_CVPR_2022_paper.pdf)）；
Mixture-of-Experts 和 GMU 按样本控制不同 expert/模态贡献的门控思想（[MoE PDF](https://www.cs.toronto.edu/~hinton/absps/jacobs.pdf)、[GMU PDF](https://arxiv.org/pdf/1702.01992)）；
以及鲁棒异常检测中使用 median/IQR 等统计量描述正常分布的思想（[PDF](https://wis.kuleuven.be/statdatascience/robust/papers/publications-2018/rousseeuwhubert-anomalydetection-wires-dmkd-2018.pdf)）。

本文的区别在于：门控不是通过异常标签训练出来的网络，而是由正常 CNN memory 的经验排名
决定；ViT 保留为基础分数，CNN 只有在正常参考中足够异常且证据强于 ViT 时，才以非负残差
补充。Sigmoid、正部差和修正上界是为统一两条分支尺度、限制局部误报而加入的本文设计。
因此不能说“公式来自 PatchCore/GMU”，更准确的说法是：**本文将正常记忆库、双尺度视觉
证据、support-only 可靠性门控和非负残差融合组合到频谱异常检测的目标域免训练场景中。**

### 频谱 TTA 的针对性设计

新增探索候选使用四个视图：原图、与数据集坐标一致的双向采集对齐扰动，以及低功率背景
噪声底抖动。前者用于覆盖 STFT 窗口起点和采集对齐差异，后者只作用于每张图灰度值低于
65% 分位数的低功率区域，加入确定性、平滑、零均值局部扰动，不直接改动高功率信号。这样
既覆盖部署时的采集变化，又保留真正的信号结构；support 和 query 使用同样的四视图，确保
这些变化被视为正常变化。代码 bundle 为
`rf_spectral_time_background_v1` 与 `ofdma_spectral_time_background_v1`。

该候选已经在 RF、Public RF 和 OFDMA 上完成受控 smoke，但结果并非所有数据集都提升，
因此当前只作为针对性探索设计，不替换正式主线，也不把它作为已经验证的普遍性能贡献。

整个推理过程只访问正常参考样本和当前待测样本。完整公式、聚合方式和实现参数见
[`论文实验部分.md`](论文实验部分.md) 第 4.1–4.3 节。

## 4. 实验范围

四个数据集均只用目标场景正常样本建立正常参考，异常样本仅用于最终评价；正常参考样本数量与
汇总方式按各数据集的观测单位定义。

| 数据集                                                  | 正常 support                                        | 测试与汇总                                                           |
| ------------------------------------------------------- | --------------------------------------------------- | -------------------------------------------------------------------- |
| In-house RF（本项目自测数据 + 合成干扰）                | 每频段 1 张 normal 图                               | 5 类异常，60 个测试单元，macro image-level                           |
| Public RF[14](https://doi.org/10.1007/s11036-009-0199-9) | 每频段 1 张 normal 图                               | 5 类异常×3 档强度，15 个测试单元，macro image-level                 |

### 传统通信方法的适用边界

ED、谱熵、谱平坦度、谱峭度和 CA-CFAR 是具有通信物理含义的统计基线，分别从能量、频谱
分布、高阶统计量或局部背景中寻找异常。由于本文统一输入 PNG 频谱图，而不是原始 IQ 数据
或连续时间快拍，这些方法在本文中属于**频谱图域适配**，不能解释为原始通信检测器的完整
复现。

KLD-Ref 是基于正常参考样本的频谱统计适配；IAD-PER 是主表中唯一的 VAE 基线；SAIFE 是
无线频谱生成式异常检测方法，本文采用少样本适配；UDMA-ResNet18 是依据论文描述完成的
重实现。监督分类方法需要异常训练样本，不符合本文的冷启动设置。具体输入边界、文献出处
和实现方式见
[`论文实验部分.md`](论文实验部分.md) 第 4.1.4 和 4.7 节。

## 7. 当前结论

- 本文方案适合“少量正常样本、异常样本缺失”的新通信场景冷启动检测。
- ViT 全局结构与 CNN 局部纹理具有互补性；相比无约束拼接或直接相加，条件融合更便于控制
  CNN 引入的误报风险。
- 四个数据集的同协议 AUROC 均领先外部基线，但 OFDMA 单分支和 FedJam 误报指标仍揭示了改进空间。
- 详细参数、全方法三指标表、文献 PDF、结果目录和复现说明统一收录在
  [`论文实验部分.md`](论文实验部分.md)。
