# 论文创新点（展示版）

## 一句话介绍

我们关注无线频谱监测系统进入**新站点、新频段或新通信配置**时的冷启动问题。新场景上线时，
现场通常先获得少量经确认正常的频谱图，异常样本和标签尚未形成。与此同时，不同场景的合法
业务占用、噪声底、信号功率和设备状态会随部署条件变化，检测器需要建立与当前场景匹配的正常
参考。

本文聚焦的问题是：**如何利用少量正常样本快速建立新场景的正常状态，并逐张识别后续频谱中的
异常？** 目标异常既可能是明显的突发、脉冲或扫频干扰，也可能是外观接近合法信号、只在局部
结构上出现细微差异的 deceptive 异常。因此，检测器需要同时刻画场景适配能力、整体时频结构
和局部异常纹理。

我们提出一种**从参数学习转向记忆学习的频谱冷启动范式**。通用视觉 backbone 保持冻结，
少量正常频谱图被直接编码为 Frequency-Aware Dual-Scale Normal Memory Bank（频谱感知双尺度
正常记忆库）。场景适配由正常参考样本的特征提取、记忆构建和近邻检索完成，检测器由此能够
快速部署到异常样本尚未形成的新场景。

## 1. 从参数学习转向记忆学习

传统异常检测通常遵循“收集数据—训练模型—部署”的流程。真实无线系统的新场景上线时通常
先获得少量正常观测，因而适合采用“冻结模型—建立正常记忆—直接查询”的部署流程：

- 目标场景部署阶段固定通用预训练 ViT 和 ResNet18；
- 使用少量已确认正常的参考样本提取特征并建立 normal memory bank；
- 查询阶段通过近邻距离判断待测频谱与正常记忆的差异；
- 以正常参考样本驱动场景适配，面向异常样本尚未形成的新部署环境。

本文所称“免训练”表示目标场景部署阶段固定 backbone 和检测参数，场景知识通过更新 normal
memory bank 写入参考记忆。系统上线或场景变化时，只需重新构建正常记忆即可完成场景适配。

该流程将场景切换压缩为一次轻量的正常记忆构建，更贴近无线监测系统的实际部署节奏。

## 2. 双尺度 normal memory bank：分离整体结构与局部纹理证据

两个分支分别建立自己的正常特征记忆：

- **ViT** 更擅长观察整张频谱图的整体结构和时间—频率布局；
- **CNN** 更擅长发现局部亮线、能量块和纹理变化。

主线中，ViT 使用 `layer1+layer2` patch 特征构建全局结构 memory，CNN 使用冻结的 ResNet18
`layer3` 构建局部纹理 memory。两类特征分别保留在异构的 normal memory bank 中，并通过近邻
距离独立生成异常证据，再在分数层完成融合。该组织方式保留 ViT 的整体判断，同时将 CNN 的
局部敏感性转化为可校准的补充证据。

In-house RF在每个场景仅使用1个宽带正常观测（1-shot）；原始频谱为适配网络输入尺寸而
沿频率轴裁切，裁切块仍属于同一次观测。Public RF按频段组织嵌套的
`k=1/2/4-per-frequency`记忆库，以评价新增正常观测对各频段覆盖的补充能力。OFDMA和
FedJam则按目标场景或数据域建立独立记忆库。

局部特征对正常场景变化较敏感，因此 CNN 分数需要结合正常参考分布进行校准。为此，
我们设计了 **Memory-Calibrated Confidence Fusion（记忆库校准的置信度融合）**：

- ViT 先给出基础判断；
- 只有当 CNN 的证据在正常参考分布的高分位区间内足够可靠时，CNN 才以非负修正的形式补充异常分数；
- 当 CNN 证据未达到该条件时，最终结果保持 ViT 的判断不变。

可以把它理解成：**ViT 是主判断，CNN 是经过正常参考分布校准后提供补充证据的辅助判断。**

该设计将 CNN 的局部敏感性转化为受正常参考约束的补充证据，重点提升融合分数的误报稳定性。
实验中保留 Direct OR 作为强对照，用于比较简单融合与置信度校准在排序能力和误报控制上的差异。

## 3. 建立可复现的新场景 OFDMA 评测协议

为了测试方法是否真的适合冷启动，我们构建了按目标场景组织的 OFDMA 实验协议：

- 每个场景分别建立自己的正常参考集；
- 设置 1-shot、2-shot 和 4-shot 三种少样本条件；
- 测试中同时包含正常变化和多种 jammer 异常；
- 所有方法使用相同的场景划分、正常参考集和评价方式。

该协议直接评估方法从少量新场景正常图像建立参考并完成场景适配的能力。

## 4. 四个数据集采用统一的核心方法口径

In-house RF、Public RF、OFDMA 和 FedJam 的统一主比较集合均为：ED、SCSE（正常参考校准频谱统计集成）、IAD-PER、UDMA、GRETEL（spectrogram adaptation）、TFAM-AAE（spectrogram adaptation）、
PatchCore、SPADE 和本文 Ours。ViT 统一使用
`layer1+layer2`，CNN 统一使用 ResNet18 `layer3`；RF/FedJam 使用 5-NN，OFDMA 使用
验证阶段冻结的 1-NN 和第三高 patch。上述配置对应各数据集的坐标组织与观测聚合协议，
主干模型和双尺度结构保持一致。

IAD-PER 是主表中唯一的 VAE 基线；VAE-MSE、Deep SVDD、PaDiM、STFPM 等已完成结果移入
补充实验。PatchCore、SPADE 属于保留的外部视觉异常检测基线；
GRETEL 属于通信频谱领域的图注意力异常检测基线。传统统计、外部视觉基线和本文方法均已在
RF、OFDMA、FedJam 的对应主协议上完成评估；内部 ViT-only 和 CNN-only 作为消融，非主协议
结果列入补充实验记录。

## 展示时可以这样总结

> 我们提出一种从参数学习转向记忆学习的频谱异常检测范式：目标场景无需训练模型，只用少量正常样本建立频谱感知双尺度 normal memory bank；ViT 记忆整体结构，CNN 记忆局部纹理，再通过正常记忆校准的置信度融合完成可靠检测。

本文的主方法是 **training-free frequency-aware dual-scale normal memory +
Memory-Calibrated Confidence Fusion**。频谱 TTA 已纳入正式主线，用于扩充少样本正常 memory
的覆盖范围；它作为辅助机制单独进行匹配消融，并报告其在各数据集上的实际变化。功率残差、
PCA 与局部特征扩充保留为探索性对照。
