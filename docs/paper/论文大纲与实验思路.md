# SpectraMemAD：论文大纲与实验思路

## 1. 一句话主线

面对新站点、新频段或新业务配置，目标场景往往只有极少量正常频谱图。SpectraMemAD不重新训练
模型，而是用这些正常参考建立全局和局部两类记忆，并利用正常参考分布校准两类异常证据，从而
完成逐样本频谱异常检测。

文章不是在证明“视觉模型可以做频谱分类”，而是在证明：**少量正常样本足以支持不更新参数的
频谱异常冷启动，且全局—局部记忆与正常参考校准融合比单一尺度记忆更可靠。**

## 2. 读者需要依次相信的四件事

1. **问题有现实性。** 新场景通常难以及时收集异常样本，但可获得少量已确认正常的频谱观测；
   因而需要少样本正常冷启动，而非重新训练监督检测器。
2. **已有方案并不完全适配。** 统计方法依赖阈值或稳定背景；生成模型在少量正常样本下需要拟合
   分布，容易受样本覆盖不足影响；工业视觉记忆方法没有专门同时处理频谱的整体占用结构和局部
   干扰纹理。
3. **方法为什么合理。** ViT记忆整体时频布局，CNN记忆局部亮线、脉冲和纹理；二者各自检索
   正常记忆，不直接拼接异构特征。CNN证据只有在正常参考下确实异常、且强于ViT证据时才修正
   分数。
4. **结果是否支持上述设计。** 与传统通信、生成式和视觉记忆基线比较证明总体性能；消融证明
   双尺度记忆和正常参考校准融合分别带来作用；不同正常参考数量证明冷启动与样本扩展能力。

## 3. 文章结构

### I. 引言：问题、缺口和贡献

写作目标：让读者在方法出现前就理解为什么“不更新目标场景参数、只用少量正常样本”是核心约束。

- 场景：频谱图中的合法业务、噪声底和接收功率会随站点与频段变化；异常样本难以覆盖。
- 任务：给定少量目标场景正常参考，对后续频谱图逐张判断，不使用异常训练样本或测试批次统计。
- 现有方法局限：统计检测、生成式检测和工业视觉记忆方法各自的适用边界。
- 方法概览：冻结视觉编码器、建立双尺度正常记忆、执行正常参考校准融合。
- 贡献只保留三项：
  1. 少量正常参考驱动的免训练场景适配；
  2. 面向频谱的全局—局部双尺度记忆；
  3. 不训练融合网络的正常参考校准融合。

### II. 方法：回答“怎么做、为什么这样做”

#### A. 问题定义与流程

- 定义正常参考集、待测频谱图和少样本协议。
- 强调目标域不反向传播、不微调、不使用异常标签；每张测试图独立处理。
- 用一张整体架构图展示 support path 与 test path。

#### B. 频谱感知双尺度记忆

- 正常参考图及其频谱增强视图同时输入 ViT 和 CNN。
- ViT特征描述整体时频布局；CNN特征描述局部纹理突变。
- 两类特征分别经过 coreset、分别以1-NN检索、分别汇总为全局分数和局部分数。
- 说明 TTA 仅扩充正常参考记忆，不对测试图做多视图推理；它是稳健性设计，不作为主要创新点。

#### C. 正常参考校准融合

- 用正常参考分数的中位数和四分位距统一两条分支尺度。
- ViT分数是基础判断；CNN只有进入自身正常分布的高分位、且校准后强于ViT时，才作非负修正。
- 给出融合公式，并逐项解释“稳健标准化、上尾条件、非负修正”分别在解决什么问题。

### III. 实验：回答“是否有效、为什么有效、适用到哪里”

#### A. 协议与公平性

- 四个数据集分别说明观测单位、正常参考数量和测试集；In-house RF按原始宽带观测计为1-shot。
- 所有方法使用相同的正常参考与测试划分，并报告 AUROC、AUPRC 和 FPR@95%TPR。
- 明确传统统计方法是在PNG频谱图上的域适配版本；生成式方法、视觉方法和本文方法的训练要求。

#### B. 主比较：是否优于有代表性的外部方案

保留的外部基线分为四组：

| 类别 | 建议方法 | 要证明什么 |
| --- | --- | --- |
| 传统统计 | ED、SCSE | 仅依赖能量/统计量在场景变化下的边界 |
| 通信频谱模型 | IAD-PER、UDMA-ResNet18、GRETEL、TFAM-AAE | 需要拟合频谱正常分布或频谱结构的方法在少样本下的表现 |
| 视觉记忆 | PatchCore、SPADE | 免训练近邻检索本身有效，但未针对双尺度频谱结构设计 |
| 本文 | SpectraMemAD | 双尺度记忆和正常参考校准带来的增益 |

主结果按数据集分开呈现：

1. **In-house RF：** 固定1-shot，验证宽带真实采集场景。
2. **Public RF：** 每频段 $k=1,2,4$，验证正常参考增加时的变化趋势。
3. **OFDMA：** $1,2,4$-shot，验证多场景、多感知单元下的冷启动能力。
4. **FedJam：** $1,2,4$-shot，仅使用频谱图，验证跨来源数据的泛化边界。

主结果的表述规则：只说表中实际领先的指标。FedJam需如实说明PatchCore在
FPR@95%TPR上更低，避免写成“所有指标均最好”。

#### C. 消融：每张表只回答一个问题

| 消融对象 | 对比 | 要回答的问题 |
| --- | --- | --- |
| 双尺度记忆 | ViT单分支、CNN单分支、SpectraMemAD | 两种尺度是否互补，而非单独依赖某一分支？ |
| 正常参考校准融合 | ViT单分支与最终方法 | 融合是否带来稳定的性能增益和更低误报？ |
| 正常参考数量 | $1/2/4$-shot | 更多正常参考能否改善或稳定目标场景记忆？ |

不把下列内容与外部基线并列，也不将其包装为独立方法：layer选择、coreset比例、TTA具体变换、
不同融合尝试。这些内容只在实现细节或补充材料中简要交代；除非它们被正式设计为一个可复现且
稳定的研究结论。

## 4. 实验结果的解释框架

每个数据集的结果按同一顺序写：

1. 先报告 SpectraMemAD 相对最强外部基线的主要增益；
2. 再说明随正常参考数变化的趋势；
3. 最后解释数据特点与边界，而不把所有现象都归因于方法设计。

可用的解释方向：

- **RF：** 合法占用随频段变化，整体布局与局部纹理都具有判别价值；双尺度证据互补。
- **OFDMA：** 多感知单元和局部频谱扰动并存，局部分支可补充整体布局判断。
- **FedJam：** 真实OTA背景与Wi-Fi业务变化更复杂；PatchCore在高召回点的误报更低，说明本文
  方法的局部误报控制仍有改进空间。

## 5. 最小、完整的实验闭环

当前论文要完成的最低证据链为：

```text
少量正常参考可建立记忆
        ↓
四个数据集、统一划分下的主比较
        ↓
ViT / CNN / SpectraMemAD 消融
        ↓
1/2/4-shot 扩展曲线
        ↓
报告优势，也如实报告 FedJam 的高召回误报边界
```

只要这条证据链完整，文章就能清楚地证明主张。后续新实验应先回答一个明确问题；若不能增强
这条证据链，就不进入主文。

## 6. 写作时的检查清单

- 方法名称统一使用 **SpectraMemAD**；融合模块称为“正常参考校准融合”，不单独使用缩写。
- “免训练”统一说明为**目标场景不训练**，不暗示视觉骨干从未预训练。
- 明确推理仅使用视觉编码器，不使用文本提示、文本编码器或图文相似度。
- 每项外部方法均给出真实文献出处；引用编号按首次出现顺序递增。
- 结果表、图和正文对 shot 的计数单位保持一致。
- 不把 TTA、coreset 或层选择作为主创新点；它们服务于主线方法的稳健实现。
