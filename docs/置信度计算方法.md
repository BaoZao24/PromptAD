# 正常支持集校准的 CNN 置信度门控

## 目的

我们的 CLS 系统有两条视觉分支：

- ViT normal patch memory：提供全局结构偏离分数 `s_vit(x)`；
- CNN local memory：提供局部纹理偏离分数 `s_cnn(x)`。

两条分支各有擅长场景。CNN 分数不能在每张图上都同等参与融合：当它的分数仍在正常样本的自然波动范围内时，可能只是局部纹理变化；只有它明显超出正常范围时，才应增强其异常证据。

本方法只为 CNN 计算这种“是否值得介入”的置信度。它不需要异常训练样本、异常原型、测试标签或额外训练的 confidence head。

## 1. 正常支持集的 Leave-One-Out 分数

设部署时已经收集到 `N` 张确认正常的支持图：

```text
S = {n_1, n_2, ..., n_N}
```

对每张支持图 `n_i`：

1. 从 CNN normal memory 中移除 `n_i` 的全部 patch；
2. 用剩余 `N - 1` 张正常图建立 PatchCore memory；
3. 计算 `n_i` 的图像级 CNN 异常分数 `r_i`。

得到正常参考分数：

```text
R_normal = {r_1, r_2, ..., r_N}
```

必须使用 leave-one-out。若让 `n_i` 与自身 patch 匹配，它的距离会异常低，不能代表真实正常图在部署时的分数范围。

当前 `per_frequency` 协议中：

- self RF：24 张 pooled 正常支持图；
- public RF：16 张正常支持图。

## 2. 正常阈值与波动范围

从 `R_normal` 计算：

```text
tau   = percentile(R_normal, 0.95)
sigma = std({r in R_normal | r <= tau})
```

`tau` 是正常 CNN 分数的上界参考，`sigma` 描述正常区域内的自然波动。使用 95% 分位数是固定的通用设置，不随异常类别、JSR 或测试标签调整。

## 3. CNN 置信度

对于测试图 `x`，先按现有 CNN PatchCore 路径得到原始图像级分数 `s_cnn(x)`。计算它相对正常上界的标准化偏离：

```text
z_cnn(x) = (s_cnn(x) - tau) / max(sigma, epsilon)
```

再映射为 `[0, 1]` 的单侧置信度：

```text
c_cnn(x) = sigmoid(z_cnn(x) / T)
```

当前固定 `T = 1`。

含义：

- `s_cnn(x)` 未超过正常上界：`c_cnn(x)` 较低，CNN 不应主导异常判断；
- `s_cnn(x)` 明显超过正常范围：`c_cnn(x)` 接近 1，CNN 局部异常证据被保留；
- 这是一种单侧异常置信度，不把“CNN 明确认为正常”转换为额外的异常分数。

## 4. 最终融合

在每个测试单元内，将两条图像级异常分数按该单元的无标签分布缩放到 `[0, 1]`：

```text
v(x) = minmax(s_vit(x))
c(x) = minmax(s_cnn(x))
```

最终异常分数为：

```text
S(x) = 1 - (1 - v(x)) * (1 - c_cnn(x) * c(x))
```

ViT 始终提供基础异常证据；CNN 只按 `c_cnn(x)` 介入。该规则没有根据异常类型选择分支，因此对 burst、chirp、DSSS、pulse 等所有异常使用同一公式。

## 5. 协议边界

分数构建允许使用：

- 已确认正常的支持图；
- 当前待评估的测试图本身及其无标签分数分布。

分数构建禁止使用：

- 测试图的 normal / abnormal 标签；
- 测试异常样本、异常 mask 或异常类别；
- 由测试标签筛选出的“正常测试图”。

测试标签只在全部分数计算完毕后，用于报告 AUROC、AUPRC 等指标。

## 6. 当前全量结果

在 `per_frequency` 协议下，使用 95% 分位数：

| 协议 | 简单均值融合 | 本方法 | 变化 |
|---|---:|---:|---:|
| self RF，60 单元 | 91.88 | 92.22 | +0.34 |
| public RF，12 单元 | 88.59 | 88.88 | +0.29 |

按异常类型，该规则提升了多个类型，也会在部分 DSSS 单元上低于简单均值。因此主结论基于所有类型的宏平均，而不是单一异常类型。
