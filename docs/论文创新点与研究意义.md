# 论文创新点（展示版）

## 一句话介绍

我们关注无线频谱监测系统进入**新站点、新频段或新通信配置**时的冷启动问题。系统刚部署
时，现场通常只能快速采集到几张确认正常的频谱图，还没有积累真实异常，更不可能提前收集
覆盖各种类型和强度的异常样本。与此同时，不同场景的合法业务占用、噪声底、信号功率和
设备状态并不完全相同，直接沿用旧场景的判断标准，容易把新场景中正常的变化误报为异常。

真正需要解决的问题是：**在只有少量正常样本、没有目标场景异常样本的条件下，如何尽快
认识这个新场景的正常状态，并逐张识别后续频谱中的异常？** 这些异常既可能是明显的突发、
脉冲或扫频干扰，也可能是外观接近合法信号、只在局部结构上略有差异的 deceptive 异常。
因此，检测器既要能适应新场景，又不能因为正常背景的轻微变化产生大量误报。

我们提出一种**从参数学习转向记忆学习的目标域免训练范式**。通用视觉 backbone 保持冻结，
少量正常频谱图被直接编码为 Frequency-Aware Dual-Scale Normal Memory Bank（频谱感知双尺度
正常记忆库）。系统通过更新正常记忆认识新场景，而不通过反向传播更新模型参数；因此不需要
训练目标场景分类器、不需要微调 backbone，也不需要异常样本，即可逐张完成冷启动检测。

## 1. 从参数学习转向记忆学习

传统异常检测通常遵循“收集数据—训练模型—部署”的流程。但在真实无线系统中，新场景刚
上线时往往只有少量正常观测，异常样本更难收集。我们的架构把部署流程改成“冻结模型—建立
正常记忆—直接查询”：

- 冻结通用预训练 ViT 和 ResNet18，不在目标场景反向传播或更新参数；
- 只用少量已确认正常的 support 提取特征并建立 normal memory bank；
- 查询阶段通过近邻距离判断待测频谱与正常记忆的差异；
- 不使用目标场景的异常图像和异常标签来建库、选模型或调参。

这里的“免训练”是**目标域免训练**，并不是否认 backbone 在通用数据上的预训练，也不是
zero-shot。本文仍然利用少量正常样本适应目标场景，只是将“学到的场景知识”存入 normal
memory bank，而不是写入网络参数。系统上线和场景变化时主要更新 memory bank，无需等待
异常数据积累或重新训练检测器。

这使实验条件更接近真实部署，而不是普通的随机训练集/测试集划分。

## 2. 让频谱图对轻微错位更稳定

频谱图有时会因为同步误差、窗口起点不同等原因发生轻微平移。信号本身没有变，但图像中的亮线可能移动几个像素，模型却可能把它误认为异常。

我们的做法很直观：

1. 对正常 support 和待检测图像同时做相同的小幅变换；
2. 变换后的图像只和同一种变换下的正常图像比较；
3. 综合多个视图的结果。

这样，模型比较的是“同一种视角下的正常和测试图像”，而不是把不同视角混在一起比较，因此对轻微时间错位和局部纹理变化更稳健。

## 3. 双尺度 normal memory bank：让 ViT 和 CNN 分工，而不是简单相加

两个分支分别建立自己的正常特征记忆：

- **ViT** 更擅长观察整张频谱图的整体结构和时间—频率布局；
- **CNN** 更擅长发现局部亮线、能量块和纹理变化。

主线中，ViT 使用 `layer1+layer2` patch 特征构建全局结构 memory，CNN 使用冻结的 ResNet18
`layer3` 构建局部纹理 memory。两者不是把向量简单拼成一个分类器输入，而是保留为两个
异构的 normal memory bank，并分别用近邻距离生成异常证据。这样既保留 ViT 的整体判断，
又不会因为 CNN 的局部敏感性而牺牲稳定性。

在 RF 主实验中，support 还按频段组织为嵌套的 `k=1/2/4-per-frequency` 记忆库，使新增的
正常样本真正补充各频段覆盖，而不是简单重复同一频段的图像。这是 memory bank 面向频谱
数据的专门化设计；OFDMA 和 FedJam 则按目标场景或数据域建立独立记忆库。

但 CNN 看到的局部差异不一定是真异常，也可能只是正常场景变化。因此，我们没有把两个分支
直接平均，而是设计了 **Memory-Calibrated Confidence Fusion（记忆库校准的置信度融合）**：

- ViT 先给出基础判断；
- 只有当 CNN 的证据在正常 support 的参考范围内足够可靠时，CNN 才以非负修正的形式补充异常分数；
- 如果 CNN 不可靠，最终结果保持 ViT 的判断不变。

可以把它理解成：**ViT 是主判断，CNN 是经过正常 support 置信度校准后提供补充证据的辅助判断。**

这个设计的价值不是保证所有数据集上的 AUROC 都最高，而是让局部证据的作用更加可控，减少不可靠 CNN 证据带来的误报。实验中我们也保留 Direct OR 作为强对照，诚实报告两者在排序能力和误报控制上的差异。

## 4. 建立可复现的新场景 OFDMA 评测协议

为了测试方法是否真的适合冷启动，我们构建了按目标场景组织的 OFDMA 实验协议：

- 每个场景分别建立自己的正常 support；
- 设置 1-shot、2-shot 和 4-shot 三种少样本条件；
- 测试中同时包含正常变化和多种 jammer 异常；
- 所有方法使用相同的场景划分、support 和评价方式。

这样可以回答一个更实际的问题：方法能不能从几张新场景的正常图像出发，适应这个场景，而不是只记住旧场景的外观。

## 5. 四个数据集采用统一的核心方法口径

In-house RF、Public RF、OFDMA 和 FedJam 的统一主比较集合均为：ED、CA-CFAR、SCSE（正常参考校准频谱统计集成）、KLD-Ref、IAD-PER、SAIFE、UDMA、
PatchCore、WinCLIP 和本文 Ours。ViT 统一使用
`layer1+layer2`，CNN 统一使用 ResNet18 `layer3`；RF/FedJam 使用 5-NN，OFDMA 使用
验证冻结的 1-NN 和第三高 patch，这是数据集坐标与观测聚合造成的固定协议差异，不是
换了模型主线。

IAD-PER 是主表中唯一的 VAE 基线；VAE-MSE、Deep SVDD、PaDiM、STFPM 等已完成结果移入
补充实验。PatchCore、WinCLIP 属于保留的外部视觉异常检测基线；
SAIFE 属于通信频谱领域的深度生成式异常检测基线，而不是通用视觉方法。传统统计、外部
视觉基线和本文方法均已在 RF、OFDMA、FedJam 的对应主协议上完成评估；内部 ViT-only
和 CNN-only 仍只作为消融，不参与外部方法排名。文档中的“未评估”仅用于历史或尚未补齐的
非主协议结果，不能被解读为性能为零或失败。

## 展示时可以这样总结

> 我们提出一种从参数学习转向记忆学习的频谱异常检测范式：目标场景无需训练模型，只用少量正常样本建立频谱感知双尺度 normal memory bank；ViT 记忆整体结构，CNN 记忆局部纹理，再通过正常记忆校准的置信度融合和成对时频视图完成可靠检测。

本文的主方法是 **training-free frequency-aware dual-scale normal memory + paired STFT
view-consistent matching + Memory-Calibrated Confidence Fusion**。功率残差等方案属于探索性
对照，不属于最终主方法。
