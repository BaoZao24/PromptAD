# 当前频谱 TTA

## 当前正式方案

我们使用 **paired TTA**：对正常参考图和待测图施加相同的变换，分别建立对应的正常记忆库并计算异常分数，最后取四个视图中最大的异常分数。全程不训练模型、不使用异常样本，也不使用测试集统计量。

| 数据 | 四个视图 | 参数 |
|---|---|---|
| In-house RF、Public RF、FedJam | 原图、轻度模糊、沿时间轴双向小位移 | Gaussian blur `3×3`；时间位移 `±4 px` |
| OFDMA | 原图、轻度模糊、沿时间轴双向小位移 | Gaussian blur `3×3`；时间位移 `±4 px` |

两类数据的图像坐标不同：RF 与 FedJam 的时间轴是竖直方向，OFDMA 的时间轴是水平方向。因此代码中 RF/FedJam 使用上移、下移；OFDMA 使用左移、右移，但两者表达的都是同一种小幅时间对齐变化。

选择这三类变化的目的很简单：模糊减弱很细碎的噪声；时间双向小位移减少采集窗口起点轻微偏移的影响；原图保留未经处理的信号结构。

## 当前效果

| 设置 | 使用的 TTA | 结果 |
|---|---|---|
| RF burst smoke（3 个 cell） | 原图 + 模糊 + 时间 `±4 px` | max AUROC **99.48%**，top-0.05 AUROC **97.53%** |
| OFDMA 历史全量对照 | 无 TTA → 当前 TTA | overall AUROC `76.91% → 77.76%`（+0.84 个百分点） |
| FedJam 正式少样本 | 当前 TTA | 本文方法的 1/2/4-shot AUROC 为 **83.71% / 84.48% / 84.80%** |

RF、Public RF 和 OFDMA 的正式主线均保持这套配置。不同数据集的完整主结果见 [`论文实验部分`](../paper/论文实验部分.md)。

## 未进入主线的候选

我们还测试过“时间双向位移 + 背景噪声底抖动”的四视图候选。它没有稳定优于当前方案：RF burst 从 `99.48%` 降到 `95.41%`，OFDMA 小规模 smoke 从 `100.00%` 降到 `95.00%`；Public RF 只有 `87.61% → 87.65%` 的极小变化。

因此，背景噪声扰动目前只保留为探索代码，不用于论文主线。
