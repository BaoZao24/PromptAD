# 支持集驱动的频率虚警控制：方法想法与实验方案

> 状态：已完成单元级验证，未通过；保留为探索记录，不作为论文创新点。

## 一、要解决什么问题

当前方法能够输出连续的异常分数，但实际频谱监测还需要回答一个更直接的问题：

> 报警阈值应该设在哪里，才能把正常频谱的虚警率控制在目标范围内？

同一个全局阈值在不同频率位置、不同场景下往往不稳定。某些频率位置的正常背景波动更大，如果仍使用统一阈值，就容易频繁误报；另一些位置则可能阈值过松，导致异常漏检。

本方案不修改 ViT、CNN、memory bank、PCA 或 TTA，也不重新训练模型。它只利用正常 support 得到每个频率位置的正常分数范围，从而把原始异常分数转换为可部署的报警分数和报警阈值。

一句话概括：

> 只用正常 support 学习“每个频率位置正常时通常会有多大分数”，再按目标虚警率自动设定报警门槛。

## 二、为什么这是独立的创新方向

前面的 TTA、PCA 融合和特征扩充都试图改变特征或记忆库，但跨数据集结果不稳定。

本方案不再强行改变正常特征空间，而是解决检测器进入实际频谱监测系统时最关键的决策问题：

- 不需要异常训练样本；
- 不需要使用测试集统计量；
- 不需要人工为每个场景反复调阈值；
- 可以直接报告目标虚警率下的实际虚警率和检测率；
- 保持当前效果最稳定的 memory baseline 不变。

需要注意：这不是“保证 AUROC 一定提高”的方法。它的主要目标是让虚警控制更可靠，同时尽量保持 AUROC、AUPRC 和检测率不下降。

## 三、核心想法

### 1. 保留当前原始异常分数

先按当前正式主线建立正常 memory bank，并计算待测频谱的 patch 异常图。原始分数计算方式完全不变。

因此，任何性能变化都来自报警校准，而不是来自更换 backbone、TTA 或重新训练。

### 2. 用正常 support 构造“非自匹配”的参考分数

如果直接让一个正常 patch 与包含它自己的记忆库比较，分数会过低，不能代表真实部署时的正常分数。

因此，对每个正常 support patch 计算参考分数时，要临时排除它自身，再寻找其他正常特征作为最近邻。这样得到的是“一个正常特征在没有自匹配条件下的异常分数”。

这一步只使用正常 support，并且适用于 1-shot：即使只有一张 support 图，它仍然包含多个时间—频率 patch，可以排除当前 patch 后与其他正常 patch 比较。

### 3. 分频率记录正常分数范围

对每个频率位置，收集该位置正常 patch 的非自匹配分数，得到该频率位置的正常分数范围。

直观理解：

- 如果某一频率位置正常背景本来就变化大，那么正常分数上界会更高；
- 如果某一频率位置正常背景很稳定，那么正常分数上界会更低；
- 测试 patch 只有超过其所在频率位置的正常范围，才被认为有明确异常证据。

频率轴方向必须根据数据生成方式和模型 patch 网格确认，不能只凭图像显示方向判断。

### 4. 少样本时向全局正常范围靠拢

某些频率位置的 support patch 数量可能很少。若完全依赖很少的局部样本，阈值会不稳定。

因此，局部频率阈值与全局正常阈值进行平滑：

- 局部正常样本多：主要相信该频率位置自己的统计量；
- 局部正常样本少：更多借用全局正常统计量；
- 所有平滑系数仅根据 support 数量确定，不使用测试分数或标签。

这一步叫做“频率分层校准”。它不是给不同数据集调不同参数，而是在每个数据集内部自动处理局部样本量差异。

### 5. 输出报警分数与目标虚警率阈值

每个 patch 分数都会相对其频率位置的正常范围进行标准化。随后按当前主线的图像级聚合方式生成图像报警分数。

用户可以直接指定目标虚警率，例如 1%、5%、10%。系统从正常 support 参考分数中自动选取对应阈值。

测试阶段不会查看测试集正常样本或异常样本来重新设阈值。

## 四、方法流程

```text
正常 support
    ↓
当前 ViT/CNN + memory bank 特征与原始分数
    ↓
对正常 patch 做非自匹配评分
    ↓
按频率位置统计正常分数范围，并与全局范围平滑
    ↓
得到频率校准器和目标虚警率报警阈值
    ↓
待测频谱原始异常图
    ↓
按频率位置校准 → 图像报警分数 → 报警/不报警
```

## 五、实现方案

### 阶段 A：保持现有检测器不变

- 使用当前正式 ViT memory baseline；
- 不使用 TTA；
- 不使用 PCA/hybrid；
- 不新增训练参数；
- 继续保存当前 patch 位置索引。

第一轮只验证 ViT memory 分支。CNN 融合在频率校准有效后再考虑加入，避免同时修改多个分数来源。

### 阶段 B：构造正常 patch 参考分数

对每个正常 support patch：

1. 从候选记忆库中排除自身；
2. 用当前最近邻规则计算该 patch 的分数；
3. 保存其频率位置、时间位置和分数；
4. 不删除任何正常特征，也不生成虚拟特征。

实现时必须使用分块计算，避免构造完整的大型两两距离矩阵，控制显存和 CPU 占用。

### 阶段 C：建立三种校准器

| 编号 | 校准方式 | 作用 |
|---|---|---|
| C0 | 不校准，原始异常分数 | 正式基线 |
| C1 | 全局 normal-support 阈值 | 判断仅自动设阈值是否有效 |
| C2 | 每个频率位置独立阈值 | 判断频率差异是否重要 |
| C3 | 频率分层平滑阈值 | 完整候选方法 |

C3 的局部阈值在样本少时向 C1 的全局阈值靠拢；局部样本多时更接近 C2。

### 阶段 D：图像级报警

第一轮沿用当前主线的图像级 top-ratio 聚合方式。每张图输出：

- 原始图像异常分数；
- 频率校准后的图像报警分数；
- 目标虚警率为 1%、5%、10% 时是否报警；
- 当前阈值来自多少 normal-support 参考样本。

## 六、实验设计

### 1. 数据集与设置

按以下顺序进行：

1. In-house RF：正式 per-frequency support protocol；
2. Public RF：k=1、2、4 per-frequency；
3. FedJam：1、2、4-shot；
4. OFDMA：只有前三项稳定后才补充。

所有方法共享同一个 support manifest 和同一套测试集。阈值只能由对应实验的正常 support 生成。

### 2. Support 稳定性

每个设置使用至少 3 个 support 种子，例如 111、222、333。统计阈值与实际虚警率随 support 选择变化的标准差。

这是本方案的重要指标：一个可部署的阈值不应因换几张正常 support 而大幅漂移。

### 3. 主要评价指标

每个目标虚警率分别报告：

- 目标 FPR：1%、5%、10%；
- 实际测试 FPR：在测试正常样本上的真实虚警率；
- TPR：在目标 FPR 阈值下的真实检出率；
- 目标 FPR 与实际 FPR 的绝对误差；
- AUROC、AUPRC、FPR@95%TPR；
- support 种子间的均值和标准差；
- 阈值构建时间、推理时间和最大显存。

AUROC 与 AUPRC 仍需报告，但它们不是本方案唯一目标。真正的核心问题是：设定 5% 虚警率后，系统是否真的接近 5%，并且还能保持足够的检出率。

### 4. 异常类型分析

需要按异常类型分别报告：

- 窄带异常；
- 宽带异常；
- 瞬态异常；
- 弱干扰或低信噪比异常。

这可以检查频率校准是否只降低虚警，却错误地压低某一类真实异常的报警分数。

## 七、实验顺序

### 第一步：小规模正确性检查

检查以下问题：

- 非自匹配是否真的排除了当前 patch；
- 频率轴方向是否正确；
- C0 是否严格复现当前原始 memory 分数；
- C1、C2、C3 的阈值是否只来自正常 support；
- 1-shot 情况下每个频率位置是否有足够参考 patch；
- CPU、显存和运行时间是否受控。

小规模结果仅用于排错，不用于选择论文参数。

### 第二步：In-house RF 完整对照

运行 C0、C1、C2、C3 和 3 个 support 种子。

如果 C3 相比 C1/C2 没有改善实际虚警控制，说明频率分层没有价值，应停止后续跨数据集实验。

### 第三步：Public RF 与 FedJam 验证

固定 In-house RF 阶段确定的平滑规则，直接运行 Public RF 与 FedJam。

不能根据数据集、shot 或测试结果重新调整频率分组、目标 FPR 或平滑强度。

### 第四步：部署型可视化

如果完整方法有效，补充：

- 目标 FPR 与实际 FPR 的柱状图；
- 各频率位置的正常阈值分布；
- 全局阈值与频率分层阈值的误报案例；
- 不同 support 种子下阈值变化图。

## 八、通过与停止标准

满足以下条件，才考虑作为论文核心创新：

- 在至少两个数据集上，目标 FPR 与实际 FPR 的平均绝对误差明显低于 C0/C1；
- 在目标 FPR 为 5% 时，实际 FPR 尽量控制在 3% 到 7% 的范围；
- 与全局阈值 C1 相比，目标 FPR 下的 TPR 不降低超过 2 个百分点；
- AUROC、AUPRC 不出现明显下降；
- 阈值在不同 support 种子下的标准差下降；
- 不需要为不同数据集单独手工设阈值或平滑参数；
- 不增加正常 memory 的容量，不显著增加推理时间。

出现以下情况则停止：

- 频率分层阈值在少样本下比全局阈值更不稳定；
- 只在单一数据集有效；
- 为不同数据集设不同规则才能工作；
- 虚警变低但真实异常检出率明显下降；
- 使用测试正常样本后才表现良好。

## 九、论文中的潜在表述

只有实验通过后，才可以写为：

> 提出一种支持集驱动的频率分层虚警控制机制。该机制仅利用正常 support 的非自匹配分数，估计不同频率位置的正常波动范围，并在少样本位置向全局统计量平滑，从而为训练免费的频谱异常检测器提供目标虚警率可控的报警阈值。整个阈值构建过程不使用异常样本和测试集统计量。

需要避免声称严格的概率保证，除非后续给出相应的理论条件与证明。当前阶段应如实表述为“经验性目标虚警率控制”。

## 十、当前结论

已按本方案实现并完成一个 In-house RF 单元的正确复核。修复
support 自匹配后，目标 5% 的实际虚警率仍为 16.04%，且频率局部
阈值与平滑阈值均未优于全局阈值。详见
`experiments/exp_frequency_false_alarm_control_20260815.md`。

因此该方向不进入 60-cell、Public RF 或 FedJam 扩展实验，也不作为
论文创新点。当前正式检测分数和原始 memory baseline 保持不变。
