# 通信领域论文 Introduction 写作套路

## 1. 文档目的

本文档总结近两年通信与频谱异常检测论文的 Introduction 写法，并据此规划
SpectraMemAD 的引言结构。核心原则是：**先建立通信问题，再回顾通信领域的方法演进，最后由明确的技术缺口引出本文方案。**

## 3. 通用写作逻辑

近年的通信论文普遍采用以下逻辑：

> 应用场景 → 现实挑战 → 现有方法 → 技术缺口 → 本文方案 → 主要贡献

### 3.1 应用场景：说明问题发生在哪里

第一段从具体通信系统切入，交代频谱异常的对象、表现和后果。可包括非法发射、突发干扰、扫频干扰、设备异常和频谱误用，以及它们对通信质量、频谱秩序和系统安全的影响。

这一段回答三个问题：

1. 研究对象是什么；
2. 异常以什么形式出现；
3. 为什么需要及时检测。

背景应服务于研究问题，不需要用大段5G、6G和IoT发展描述填充篇幅。

### 3.2 现实挑战：说明问题为什么难

第二段把一般性的频谱异常检测收窄到本文的部署条件。通信论文常用的困难包括：

- 异常信号具有偶发性，难以提前收集和标注；
- 信号受到噪声、传播条件和设备状态影响；
- 不同站点、频段和业务负载具有不同的正常分布；
- 低功率或局部异常容易被正常背景掩盖。

对于 SpectraMemAD，本段应聚焦于**新场景只有少量正常参考频谱图**这一核心条件，进而定义少样本正常冷启动任务。

### 3.3 现有方法：按技术路线组织文献

第三段按照方法类别组织文献，而不是逐篇介绍作者和网络结构。建议使用以下顺序：

1. **统计检测方法。** 能量、谱统计量和恒虚警检测具有明确的通信含义，但依赖阈值、背景估计或信号先验。
2. **生成式与重构式方法。** VAE、AAE等方法通过正常数据学习频谱分布，但需要在目标场景训练，少量正常样本难以充分覆盖场景变化。
3. **蒸馏、记忆与结构建模方法。** UDMA、TFAM-AAE、GRETEL和MARD增强了特征建模或异常敏感性，但主要采用目标场景模型训练，尚未解决少量正常参考下的快速场景适配。

每一类文献只承担两个任务：说明已经解决的问题，并指出与本文部署条件直接相关的剩余缺口。

### 3.4 技术缺口：指出可由本文解决的具体问题

技术缺口必须能够直接推导出本文设计。SpectraMemAD 的问题链可收敛为：

1. 目标场景重新训练不利于新站点、新频段的快速部署；
2. 单一尺度难以同时描述合法信号的整体时频布局和局部干扰纹理；
3. 全局与局部分支的可靠性随场景变化，需要由当前场景的正常参考进行协调。

避免只写“检测精度仍有提升空间”“现有方法鲁棒性不足”等宽泛判断。这类表述无法解释本文为什么采用双尺度记忆和校准融合。

### 3.5 本文方案：逐项回应技术缺口

方法介绍段先讲工作机制，再给出方法名称：

1. 冻结通用预训练编码器，以记忆构建代替目标场景参数训练；
2. 分别记录整体时频结构和局部纹理的正常特征；
3. 将待测频谱图与两类正常记忆进行1-NN匹配；
4. 使用正常参考分布校准两类异常分数的融合关系。

这一段说明输入、正常模式的表示方式、异常证据的来源和融合逻辑。网络层、超参数、数据增强幅度和实现细节放入方法或实验部分。

### 3.6 主要贡献：形成方法层次

贡献建议保持三点，并分别对应范式、方法和融合机制：

1. 从参数学习转向记忆学习的免训练场景适配；
2. 面向频谱图的全局—局部双尺度特征记忆；
3. 由正常参考分布校准的全局—局部分数融合。

贡献应直接陈述本文提出了什么、如何工作以及解决了什么问题。网络模块名称、实现步骤和单个实验结果不单独列为贡献。

## 4. SpectraMemAD 的五段式 Introduction

考虑 IEEE Letter 的篇幅，Introduction 建议写成五个主体段落，随后列出三项贡献。

### 第一段：频谱异常检测场景

介绍无线频谱监测、常见异常形式及其对合法通信的影响，从实际通信任务建立研究必要性。

### 第二段：少样本正常冷启动问题

说明检测器迁移到新站点、新频段或新设备时，通常只能获得少量经确认正常的频谱图。由此定义本文的目标：利用少量正常参考建立场景模型，并对后续观测独立检测。

### 第三段：通信领域现有方法及其边界

依次回顾统计检测、生成式重构、蒸馏和记忆增强方法。段落结尾将问题收敛到目标场景训练、少量正常样本覆盖不足，以及全局与局部异常证据缺少协调。

### 第四段：本文方法

提出 SpectraMemAD，概括“冻结编码器—构建双尺度正常记忆—1-NN匹配—正常参考校准融合”的完整检测流程，并明确每项设计对应的前述问题。

### 第五段：主要贡献

用三条并列贡献概括学习范式、双尺度正常建模和校准融合。Letter 中可以省略常规的章节组织说明，将篇幅留给问题和方法。

## 5. 引言中的引用安排

### 5.1 建议数量

SpectraMemAD 的 Introduction 可引用约10–15篇论文：

| 位置 | 建议引用数量 | 文献类型 |
|---|---:|---|
| 场景与研究意义 | 2–3篇 | 频谱安全、频谱异常检测综述或代表性应用 |
| 统计检测方法 | 2–3篇 | 能量检测、谱统计量、CFAR等 |
| 生成式与重构式方法 | 3–4篇 | SAIFE、IAD-PER、TFAM-AAE等 |
| 蒸馏、记忆与结构方法 | 3–4篇 | UDMA、GRETEL、MARD等 |

引用数量服务于论证链条。每组引用应支撑一句明确判断，避免连续罗列文献但不说明它们与本文问题的关系。

### 5.2 工业视觉文献的放置边界

Introduction 只使用通信、频谱检测和无线信号分析文献建立领域发展脉络。PatchCore、SPADE等工业视觉方法不在引言中出现，分别放在以下位置：

- **方法部分：** 引用与本文正常特征记忆、近邻检索直接相关的技术来源；
- **相关工作：** 若最终保留独立章节，用一小段说明视觉异常检测提供的通用机制；
- **实验部分：** 将PatchCore和SPADE作为跨领域视觉基线进行比较。

这种安排保持通信问题链的连续性，也清楚区分通信领域已有研究、本文借鉴的通用视觉机制和实验比较对象。

## 6. 语言风格

### 6.1 每段只完成一个任务

段首先给出核心判断，后续句子提供依据，段末自然引向下一问题。不要在同一段混合背景、方法细节、实验结果和限制说明。

### 6.2 用具体机制代替宽泛评价

推荐：

> Reconstruction-based detectors require target-scene optimization and may inadequately model normal variations when only a few reference spectrograms are available.

避免：

> Existing methods still have many limitations and may not always achieve satisfactory performance.

### 6.3 控制转折和防御性说明

使用问题递进建立逻辑，不连续堆叠“然而”“尽管如此”“值得注意的是”。必要的适用范围在任务设定或实验部分集中说明，引言直接推进研究问题和本文方案。

### 6.4 统一少样本术语

中文使用“少量正常参考样本”或“正常参考集”。英文优先使用：

- `a few normal reference spectrograms`；
- `a normal reference set`；
- `few-normal-sample cold-start detection`。

除非需要正式定义 few-shot episode，不在正文中反复使用 `support`。
