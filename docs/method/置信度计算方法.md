# 置信度融合计算方法

## 为什么不能直接把 ViT 和 CNN 相加

ViT 和 CNN 输出的都叫“异常分数”，但两者的数值尺度和可靠性并不相同。ViT normal
memory 主要判断整体时频结构，是当前实验中更稳定的主分支；CNN local memory 对亮线、
脉冲和局部纹理更敏感，能够补充 ViT 漏掉的局部异常，但也更容易把正常的局部波动当成异常。

因此，直接平均、相加或取最大值会产生三个问题：

1. 两条分支的原始分数没有统一量纲，数值更大的分支可能无条件主导结果；
2. CNN 即使只对正常纹理变化产生高响应，也会被强制加入最终分数，增加误报；
3. 如果用整个测试批次做 min--max 或排名，同一张图的结果会随批次组成变化，无法逐张在线检测。

本文的设计目标不是让两个分支拥有相同权重，而是：**ViT 保留最终决定权，CNN 只有在“相对
正常状态确实反常”且“相对 ViT 提供了更强证据”时，才提供一个有上界的非负补充。**

## 公式是怎样构造出来的

记测试图像 $x$ 的 ViT、CNN 原始异常分数为 $V(x),C(x)$，正常参考分数集合为
$R_V,R_C$。公式由“统一分支尺度、判断 CNN 是否可靠、限制 CNN 的影响”三步构成。

### 第一步：用正常记忆库统一两条分支的尺度

对分支 $b\in\{V,C\}$，计算

$$
z_b(x)=\frac{S_b(x)-\operatorname{median}(R_b)}
{\operatorname{IQR}(R_b)+\epsilon}.
$$

$z_b$ 表示当前分数比正常参考的中位数高出多少个 IQR。这里使用 median/IQR，而不是
mean/std，是因为少量正常参考样本中可能存在极端视图，稳健统计量不容易被单个异常值拉偏。
这一步也解决了 ViT 与 CNN 原始分数不在同一量纲的问题。

IQR 是 **interquartile range，四分位距**，定义为

$$
\operatorname{IQR}(R_b)=Q_{75}(R_b)-Q_{25}(R_b).
$$

$Q_{25}$ 和 $Q_{75}$ 分别是正常参考分数的第 25 和第 75 百分位数，因此 IQR 描述的是
正常分数中间 50% 的波动宽度。例如 $Q_{25}=10$、$Q_{75}=14$ 时，IQR 就是 $4$。它不是
“异常概率”，也不是需要训练的网络参数，而是从当前分支的正常 memory 参考分布直接计算
得到的尺度。

在本文中，median 给出“正常分数中心”，IQR 给出“正常分数通常波动多大”。因此

$$
z_b=\frac{\text{当前分数}-\text{正常中心}}{\text{正常波动尺度}}
$$

可以理解为当前样本偏离正常状态的相对程度：偏离相同数值时，正常 IQR 小的分支会得到更大
的标准化偏离；正常 IQR 大的分支会得到更小的标准化偏离。这让 ViT 和 CNN 可以在不同原始
分数尺度下进行公平比较。实现中的 $\epsilon$ 只用于 IQR 接近 0 时避免除零。

然后将稳健标准分数压缩为有界证据：

$$
p_b(x)=\sigma\!\left(\frac{z_b(x)}{T}\right),\qquad T=2.5.
$$

这里的 $p_b\in(0,1)$ 是为了比较两分支而构造的**有界异常证据**，不是经过监督概率校准的
“异常概率”。Sigmoid 防止极端分数产生无限大的修正，温度 $T$ 则控制曲线斜率；$T=2.5$
使少量正常参考样本下的证据变化更平滑，避免某个局部分数稍高就立即饱和。

### 第二步：只有 CNN 落入正常参考的高分尾部时才开门

计算 CNN 分数相对于正常 CNN memory 的经验累积分布排名：

$$
r_C(x)=\widehat F_{R_C}(C(x)).
$$

实现中使用 mid-rank 处理并列值，并把超出参考范围的分数截断到 $[0,1]$。$r_C=0.8$
可理解为：当前 CNN 分数不低于正常参考中约 80% 的分数。正式门槛为

$$
\mathbf 1\{r_C(x)\geq 0.8\}.
$$

这相当于只允许正常分布上尾约 20% 的 CNN 响应进入下一步。需要同时使用 $z_C$ 和 $r_C$：
$z_C$ 衡量超出正常中心的幅度，$r_C$ 对分数尺度和分布形状更稳健；两者承担的作用不同。

### 第三步：CNN 必须比 ViT 提供更多相对异常证据

定义

$$
\Delta(x)=[p_C(x)-p_V(x)]_+=\max(p_C(x)-p_V(x),0).
$$

如果 ViT 已经比 CNN 更确信该图异常，CNN 没有新增信息，$\Delta=0$；只有 CNN 相对自身
正常参考的偏离比 ViT 更强时，差值才为正。这样加入的是 CNN 的**增量证据**，不是重复计算
两条分支都已经发现的异常。

最终公式为

$$
s(x)=V(x)+\alpha\,\operatorname{IQR}(R_V)\,
[p_C(x)-p_V(x)]_+\mathbf 1\{r_C(x)\geq q\},
$$

其中

$$
q=0.8,\qquad T=2.5,\qquad \alpha=2.5.
$$

最终分数以原始 ViT 分数为基准，所以需要乘 $\operatorname{IQR}(R_V)$，把无量纲的证据差
重新映射到 ViT 分数尺度。由于 $0\leq[p_C-p_V]_+\leq1$，CNN 的最大修正被限制为
$2.5\operatorname{IQR}(R_V)$。因此该规则具有两个明确性质：

- 门控关闭时，$s(x)=V(x)$，系统精确退化为 ViT-only；
- 门控开启时，$s(x)\geq V(x)$，CNN 只能加分，不能把 ViT 已发现的异常压低。

第二条只表示单个样本的分数不会被减小，并不保证 AUROC 等整体排序指标一定提高：如果某些
正常图也被 CNN 错误加分，整体排序仍可能变差。这正是 OFDMA 上融合与 ViT-only 接近、部分
shot 略低的原因，也是门控必须保持保守的原因。

## 公式来源：借鉴已有思想，但不是直接照搬某篇论文

需要准确区分“思想来源”和“公式出处”。截至目前核对的相关工作中，没有发现与本文

$$
s(x)=V(x)+\alpha\,\operatorname{IQR}(R_V)
[p_C(x)-p_V(x)]_+\mathbf 1\{r_C(x)\geq q\}
$$

完全相同的公式。本文公式是针对“少量正常参考样本、目标域不训练、测试样本逐张独立处理、
CNN 只作为可靠补充”这四个约束设计的**正常参考样本校准分数融合**。它不是把已有
论文中的门控网络公式改个符号，也不是一个训练出来的融合头。

公式中的组件分别有以下参照关系：

| 公式组件 | 可参照的已有工作 | 本文实际采用与区别 |
|---|---|---|
| 正常 memory + 近邻距离 | PatchCore 使用正常 patch 特征构成 memory bank，并用近邻距离进行异常检测 [PatchCore](https://openaccess.thecvf.com/content/CVPR2022/papers/Roth_Towards_Total_Recall_in_Industrial_Anomaly_Detection_CVPR_2022_paper.pdf) | 借鉴“正常样本记忆与检索”的范式；本文使用 ViT `layer1+layer2` 和 CNN `layer3` 两个异构 memory，并在频谱坐标语义下做 TTA，门控公式不是 PatchCore 的公式。 |
| 按样本决定分支贡献 | Mixture of Experts 的 gating network 会为不同 expert 分配不同责任 [Jacobs et al.](https://www.cs.toronto.edu/~hinton/absps/jacobs.pdf)；GMU 用可学习门控制不同模态对表示的贡献 [Arevalo et al.](https://arxiv.org/pdf/1702.01992) | 借鉴“不同样本不应固定使用相同分支权重”的思想；本文没有训练 gating network，而是用正常 CNN memory 的经验排名构造确定性门 `1{r_C≥0.8}`，因此属于正常参考样本驱动的确定性门。 |
| median/IQR 标准化 | 鲁棒异常检测文献使用 median、IQR/MAD 等稳健位置和尺度统计量降低离群点影响 [Rousseeuw and Hubert](https://wis.kuleuven.be/statdatascience/robust/papers/publications-2018/rousseeuwhubert-anomalydetection-wires-dmkd-2018.pdf) | 借鉴稳健统计思想；本文只在正常参考分布上计算 median/IQR，用于把 ViT/CNN 分数转换到可比较尺度。 |
| Sigmoid、正部差和非负修正 | 这些是常见的有界映射和残差约束 | 具体组合是本文设计：Sigmoid 防止修正无限放大，`[p_C-p_V]_+` 只保留 CNN 相对 ViT 的新增证据，非负修正保证不压低 ViT 主判断。 |
| 正常参考经验排名 | 非参数经验 CDF/百分位排名 | 这是对正常 memory 的无参数尾部判断；本文不把它称为 conformal prediction，也不声称提出了新的 CDF 估计方法。 |

所以，论文中应写成：**本文借鉴 memory bank、专家门控和鲁棒统计的基本思想，提出一个不
需要目标域训练的正常参考样本校准非对称分数融合规则。** “非对称”指 ViT 是基础分数，CNN
只能在满足正常参考可靠性条件时提供非负增量；这正是本文与普通平均、最大值、可学习 GMU
或传统 Mixture-of-Experts 的区别。

不能写成“首次提出门控融合”或“公式来源于 PatchCore/GMU”。更准确的创新表述是：**把
正常记忆库、双尺度视觉证据、正常参考样本可靠性门控和非负残差融合组合到频谱异常检测的
目标域免训练冷启动场景中。**

## 一个具体例子

假设某张图的 ViT 分数比 ViT 正常中位数高 $1$ 个 IQR，而 CNN 分数比 CNN 正常中位数高
$3$ 个 IQR，并且 CNN 的正常参考排名为 $0.92$。则

$$
p_V=\sigma(1/2.5)\approx0.599,\qquad
p_C=\sigma(3/2.5)\approx0.769.
$$

因为 $0.92\geq0.8$ 且 $p_C>p_V$，门控开启：

$$
s(x)\approx V(x)+2.5\operatorname{IQR}(R_V)(0.769-0.599)
=V(x)+0.425\operatorname{IQR}(R_V).
$$

如果同一 CNN 分数的参考排名只有 $0.70$，或者 $p_C\leq p_V$，修正项立即变为 0，最终结果
就是原始 ViT 分数。

## 三个常数是怎么来的

公式结构来自上述部署约束；`q=0.8`、`T=2.5`、`alpha=2.5` 的具体数值则是**离线开发阶段的
经验选择，不是理论上唯一的闭式最优解**。

初始实验在冻结的 RF 分支分数上比较了直接残差、排名差、Sigmoid 残差、不同上尾门槛和不同
修正强度。正式组合 `q=0.8, T=2.5, alpha=2.5` 被选为保守方案：相对 ViT-only，固定
正常参考样本开发结果由 In-house RF 的 `90.93/80.70/24.73` 提高到
`91.97/81.80/22.00`，Public RF 由 `79.37/44.82/51.77` 变为
`80.10/44.59/49.64`，数值依次为 AUROC/AUPRC/FPR@95%TPR。它在两个 RF 数据集上同时
改善 AUROC 和 FPR95，并把 Public RF 的 AUPRC 代价限制在 0.25 个百分点以内。更激进的
`alpha=8` 虽然平均 AUROC 更高，但牺牲了更多 Public RF AUPRC，因此没有采用。

随后又对 `q/T/alpha` 做了 252 组开发/留出搜索。RF 上更激进的开发最优组合
`q=0.6, T=1.5, alpha=5.0` 在五个 OFDMA 验证场景上相对正式组合造成 AUROC −2.682、
AUPRC −1.911、FPR95 +12.2 个百分点，说明它明显过拟合 RF。因而没有追逐单个数据集的
最高分，而是保留 `0.8/2.5/2.5`，并在后续数据集上原样冻结。

必须区分两件事：门控的**在线计算**只使用正常参考样本，不读取异常标签或其他测试样本；
三个超参数的**离线确定**使用了开发实验指标。论文中应表述为“在开发阶段确定并冻结，正式
推理采用正常参考样本校准”，不能写成三个数由理论推导得到，也不能写成超参数选择完全没
看过开发标签。

## 唯一正式规则

系统有两条 normal-memory 分支：

- ViT：主要结构异常证据；
- CNN：辅助局部异常证据。

正式融合按单张测试图片独立计算，只读取当前图片的 ViT/CNN 原始分数和正常参考
参考分布，不读取测试标签，也不读取异常类型或其他测试图片。

## 分数归一化

ViT 和 CNN 分别用正常参考分布的中位数和 IQR 做稳健标准化：

```text
z_v = (ViT score - median(ViT support)) / (IQR(ViT support) + eps)
z_c = (CNN score - median(CNN support)) / (IQR(CNN support) + eps)
p_v = sigmoid(z_v / 2.5)
p_c = sigmoid(z_c / 2.5)
```

再计算 CNN 分数在正常参考集合中的经验 CDF 排名：

```text
r = support_empirical_rank(CNN score, CNN support)
```

## CNN 置信度补充

CNN 只有同时满足两个条件时才以非负修正的形式补充 ViT：

1. CNN 在正常参考集合中的排名至少为 0.8；
2. 平滑后的 CNN 证据强于 ViT。

固定公式为：

```text
cnn_advantage = clip(p_c - p_v, 0, 1)
confidence_correction = indicator(r >= 0.8) * cnn_advantage
final = ViT score + 2.5 * IQR(ViT support) * confidence_correction
```

因此，CNN 排名不高或不强于 ViT 时，`confidence_correction=0`，最终分数完全退化为 ViT 原始分数。
该规则只允许 CNN 加分，不会因不可靠的 CNN 证据降低 ViT。

固定参数只有：

```text
support_rank_q = 0.8
temperature = 2.5
alpha = 2.5
```

这些参数写死在正式实现中，不提供命令行调参接口。旧的 test-batch 校准规则只用于协议
对照，不作为正式方法。

## 代码入口

- 正式融合公式：`utils/confidence_gate.py`（模块名保留用于兼容，论文名称为 Confidence Fusion）
- 正式融合入口：`tools/eval_cls_dual_visual_evidence_fusion.py`

正式命令只有：

```bash
python tools/eval_cls_dual_visual_evidence_fusion.py \
  --protocol rf_target \
  --vit-score-dir <vit>/scores \
  --cnn-score-dir <cnn>/scores \
  --vit-reference-dir <vit-reference> \
  --cnn-reference-dir <cnn-reference> \
  --output-root <fusion>
```

ViT score 固定读取 `vit_patchcore_max_scores`。CNN 辅助分支在四个数据集统一固定为
ImageNet ResNet18 `layer3`、完整 local memory、单最近邻和最高 10% patch 距离均值；
不同结果目录中的字段名可能分别写作 `resnet18_layer3_top0.1_scores` 或
`cnn_layer3_top0.1`，它们都指向同一 CNN-only 分支定义。

OFDMA target-scene 使用独立正式入口；其 ViT 近邻为 1-NN，图像分数是四视图 anomaly
map 的第三高 patch，再在 21 个 SU 上取最大值。RF 和 FedJam 的 ViT 近邻为 5-NN
距离均值。上述数据集特定的聚合差异不改变统一的 RF/OFDMA/FedJam 正常参考样本校准
置信度融合公式。

PatchCore-style CNN 的 `scores` 是独立 baseline，不能接入 Ours 的融合入口。融合
入口只接受数据协议和输入、输出路径，不接受分数字段选择、融合公式、阈值、权重
或分支选择参数。

## 使用限制

该规则只使用正常参考分布，属于**严格的正常参考样本驱动推理**：

- 不使用测试标签；
- 不使用其他测试图片；
- 可以逐张图片在线计算；
- 当正常参考分支为常数时，IQR 加上 `eps`，不会发生除零。

旧批次级校准版本的对照结果必须单独标注为协议对照，不能与正式正常参考样本校准
结果混写。
