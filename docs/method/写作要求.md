
 写作三要点
●言简意赅：让每个词都有存在的意义
    不等于“内容简单”，是指文字的“信息密度高”，是尊重读者时间、增强论文可读性和说服力的首要原则。
（1.1）删除冗余词汇，使用强动词（见表格实例）
（1.2）避免重复：在同一段落中，对同一概念使用一致的术语，无需用不同说法反复描述。
（1.3）避免长句：确保每个句子只传达一个核心信息，过长的复合句容易造成逻辑混乱、指代不清。

●专业表述：让同行能清晰、无歧义地理解我们的工作。
    确保了文字交流的高效性，关乎准确性、一致性和客观性，是学术可信度的基石。
（2.1）术语准确：严格使用本领域的标准术语。避免用口语化或比喻性语言（如“结果很棒”），而应定量描述（如“效率提升了15%”）。
（2.2）语气客观：使用主动语态以强调施动者、创新主体（如“We propose...”）；使用被动语态（尤其在方法部分，如“The experiments are conducted”）以强调客观事实。避免个人化、情绪化的表达（少用“I believe”, “surprisingly”需谨慎）。
（2.3）指代清晰：慎用“it”, “this”, “that”等代词，确保其指代对象绝对明确，否则宁可重复名词。
（2.4）时态统一：遵循惯例（见表格实例）

●逻辑结构：通过清晰的结构和路标，从问题起点，引向结论的终点。
    优秀的科技论文不是信息的堆砌，而是一个引导读者逐步理解并最终信服你的观点的论证过程。逻辑结构是这个过程的“路线图”。
（3.1）“总分”结构：全文、章节、段落、甚至句子，一般遵循“总-分”结构（不一定完全是，具体情况具体分析）。开头明确告知读者本部分目的、核心论点，再展开细节，阐述各个论据。段首为主题句，段中为支撑证据（数据、文献、推理，可用First, Second,Third,...），段尾可进行小结或承上启下。
（3.2）“故事线”思维：在写作前，一定要学会用一两句话凝炼中心思想：“为了解决（x场景中的xx问题），我们通过（xx方法），发现了（xx结果），揭示了（xx机制、理论），展示了（xx性能优势）。”
（3.3）善用路标词：使用“However,” “Therefore,” “In contrast,” “Furthermore”等词，明确标示句子间的逻辑关系（转折、因果、对比、递进），主动引导读者思路。

科技论文写作经验总结

时态用法
建议用法	Introduction中文献介绍部分，统一使用一般现在时态
	正文中，统一用一般现在时态。预告内容时，可以使用将来时态
	总结中，统一使用现在完成时态

动词单复数形式
建议用法	一定要仔细检查动词的单复数！

段落布局
建议用法	避免一行只有一两个单词，不美观，看起来比较突兀
	注意两端对齐
	公式后的where或者“其中”，不需要另起一行，顶格
	三个并列用and，比如a, b, and c，注意：and前面加逗号

固定词组
常见错误	建议用法
is denoted as	is denoted by...或者let xxx denote xxx
英文标点后忘记空格	不同于中文标点，英文标点后必须人为手动空格
The receiver performs the detection of the spectrum hole.	The receiver detects the spectrum hole.
应该使用强动词，perform这类动词比较弱，无具体含义，类似还有obtain，provide等
compared to the baselines
暗含 比作，不适合用于 对比	compared with the baselines 对比
For a given	Given a...
,that is, ...	i.e., ...
After obtaining	Using
provided a detailed analysis of ...	detailed ...
xxx, so xxxx	杜绝这种口语化句型

序词用法
常见错误	建议用法
at k-th time slot	at the k-th time slot, 一定要加上不定冠词
the i-th client，the i-th user, the i-th device..	不同于时隙，“用户”等主语不需要排序，直接用client i, user i, device i，简洁方便
Equations的简写错误	Eqns.，特别是在response letter里用

所有格用法
常见错误	建议用法
后续名词很长时用 's
each node’s cumulative reputation score	the cumulative reputation score of each node
当后续名词很短，可以不用's，例如：the system performance

数学符号下标：正体 vs 斜体
斜体下标：用于表示变量、索引；例如：s_t，t是时间变量	正体下标：用于文字说明、缩写、固定含义；例如：u^{\text{SU}} 表示SU的效用

- u 是主符号(效用 utility)
- SU = Secondary User (文字缩写)
- SU 是身份标识,不是数学变量,因此用正体

公式格式
●公式后，用where句式解释公式中的符号时，两或三个符号之间用and，比如
where x denotes the power gain, and y is the uplink channel coefficient from user A to the base station. 如果两个句型比较对称，可简写为 where x and y denote the power gian and the channel coefficient respectively.
●解释多个符号，特别是某个符号需要用两句解释时，建议用分号，比如
where x[i] denotes the power gain with i being the index；
●每个公式后要有标点，一般是逗号和句号。如果公式后还有解释，用逗号；如果公式作为结尾，用句号。
●一般来说（除非强化学习有一套固定符号用法），矩阵用大写加粗，如H；向量用小写加粗，如g；集合用花体不加粗，如ℋ。
●如果不清楚三角等号≜的用法，就直接用等号代替=。两者用法不一样！

图片、表格、伪代码位置
一般需要顶格放置；一页如有多个图片、表格、伪代码，按实际情况放置

英文缩写
英文缩写，如果后续文中没有被用到，就不需要定义

统一标题大小写
标题大小写统一，检查首字母是否大小写

句首单词
常见错误	建议用法
数字、英文缩写、数学符号一般不作为句首的第一个单词。错误写法如下：
xx（上一句结尾）. 2 is xxxx
xx（上一句结尾）. STBC is used by xxxx
xx（上一句结尾）. μ2 denotes xxxx 	可以在数字、英文缩写、数学符号前面加上一个连接词。正确用法如下：
xxxx. Moreover, 2 is xxxx
{However/Further/Additionally...均可}

标点符号类
常见错误	建议用法
xxx is defined as:
      y=hx+n   (1)
xxxx is：
       y=hx+n  (1)	公式前面这句话还没有说完，后不加冒号
xxx is defined as
      y=hx+n   (1)
类似的有is given by, becomes, is rewritten as, is simplified as...
We define p as the probability of success detection
p=xxxxx (1)	公式前面这句话已经说完，最后要加冒号
We define p as the probability of success detection：
p=xxxxx (1)
... based on Eqn. (1).	不需要Eqn. ，直接说 based on (1)

从句类
常见错误	建议用法
一句话连续用多个+ing从句	最多用一个，或者不用
it means/implied + 独立完整的句子	it means/implied that + 独立完整的句子

仿真结果描述
建议结构	常用词汇
第一句：图X展示了XXX下XXX的XXX性能；
图X比较了在XXX下XX（所提方法）和XX（基准）的XX性能。	Fig. X shows/depicts/illustrates XXXX of xxxx {所提算法名字} under XXX.
Fig. X compares XXX{性能} of XXX{所提算法} with XXX{baseline算法} under XXX.
第二句：补充说明一些针对当前图表的具体参数设置{不是必须，视具体情况而定}。	In this figure, consider that XXX.
第三句：以分点的形式表示图表结果。
首先，XXX。其次，XXX。最后，XXX。
注意，先描述最显著的、最想让读者看到的结果。每个观察点后，根据需求可以突出两点：
1.实验结果与【哪个定理，公式，章节】里的理论结果一致。
2.前面理论没有展示，只是实验出来的结果，那就可以解释原因。	First, it is observed that/we observe that XXXX. This observation shows that/This indicates that/ This is because XXXX. Second, XXXX. Third, XXXX. These observations demonstrate/corroborate/highlight XXXX.注意不能用verify，因为不能用实验或仿真结果去验证xxx
