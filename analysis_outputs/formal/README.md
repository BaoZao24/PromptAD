# 正式论文结果

本目录只放当前论文可以直接引用的最终运行入口。每个条目链接到保留在 `analysis_outputs/` 根目录的原始日期运行目录。

- `inhouse_rf/`：In-house RF 的统一 target-scene 支持集协议。
- `public_rf/`：Public RF 的 k-per-frequency 协议。
- `ofdma/`：OFDMA target-scene cold-start 协议。
- `fedjam/`：FedJam 的 benign-only 少样本协议。
- `paper_figures/`：由正式结果生成的论文图表。

不要将 `smoke_validation/` 或 `exploratory/` 中的数值写入论文主表。
