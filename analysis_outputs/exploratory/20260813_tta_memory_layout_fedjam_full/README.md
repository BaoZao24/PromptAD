# 合库与分库正常记忆对照（FedJam）

目的：检验四个频谱增强后的正常特征合并为单一记忆库、测试频谱只编码一次，是否优于当前的分库配对查询。

相同条件：FedJam 完整独立 test（7,200 条）；train 中固定抽取 benign-only 嵌套 1/2/4-shot support；`identity + 3×3 blur + 时间轴正/负平移 4 px`；同一随机种子、同一 checkpoint、相同 CNN 分支和 support-only 融合规则。合库的 coreset 数量严格匹配四个分库之和：1/2/4-shot 均为 448/900/1,800 个 ViT 特征。

| 支持数 | 分开记忆库：最终 AUROC | 合并记忆库：最终 AUROC | 差异（合并－分开） | 合并记忆库 FPR@95%TPR 差异 |
|---:|---:|---:|---:|---:|
| 1-shot | 83.71% | **85.16%** | **+1.45 pp** | +0.11 pp |
| 2-shot | 84.48% | **85.99%** | **+1.51 pp** | -0.61 pp |
| 4-shot | 84.80% | **86.33%** | **+1.53 pp** | +2.72 pp |

结论：FedJam 上合库在三种 support 数量、三类攻击的 AUROC 都更高，且测试编码次数从 4 次降至 1 次。代价是 4-shot 的高召回误报率变差。因此它是 FedJam 的有效备选，而不是替换全部数据集主线的统一结论：RF 完整对照总体仍与分库持平。

- `separate/`：当前分库配对 TTA 的完整结果。
- `merged_matched_count/`：严格匹配总特征数的合库结果。
