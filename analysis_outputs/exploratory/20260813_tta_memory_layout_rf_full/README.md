# 合库与分库正常记忆对照（RF）

目的：验证“将四个频谱增强后的正常特征合为一个记忆库、测试图只查询一次”是否优于当前的分库配对 TTA。

相同条件：4 个 RF 场景、5 类干扰、60 个场景/强度单元；每场景 24 张正常 support；`identity + 3x3 blur + 时间正/负平移 4 px`；同一 support manifest、随机种子与 coreset（0.1）。两组最终均保存 8,640 个特征。

| 记忆组织 | 测试查询 | AUROC（60 单元宏平均） | 相对分库 |
|---|---:|---:|---:|
| 分开记忆库 | 4 次（各视图配对） | 91.633% | — |
| 合并记忆库 | 1 次（仅原图） | 91.628% | -0.005 pp |

结论：总体几乎持平，不能声称合库更好。分库在 38/60 个单元不低于合库，且在 burst、chirp、DSSS 上更稳定；合库在 deceptive 干扰上平均高 1.89 pp。当前主线仍保留分开记忆库；合库作为低查询成本的备选方案。

- `separate/`：分开记忆库的完整结果。
- `merged/`：合并记忆库的完整结果。
